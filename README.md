# 2AM App Ideas — #01

## Instagram-inspired prototype: Save With Context

I wanted to explore one small feature I wish existed: **Save With Context**.

The idea is simple: save a post, add a quick note about why you saved it, and find that context later. Because sometimes you save a post and, two weeks later, have absolutely no idea why you saved it. 😭

🔗 **[Try the live prototype](https://2amappideas1.netlify.app/)**

## About the experiment

This prototype is part of **2AM App Ideas**, a weekly experiment of taking familiar apps and turning small “what if?” ideas into working prototypes.

The challenge is simple:

> One app. One week. One feature.

For Week 01, I picked Instagram—not to rebuild it or create another social media clone, but to turn one small idea into a working prototype.

## The idea: Save With Context

This version lets you:

- Save a post for later
- Add a short note explaining why you saved it
- Find the reason behind a saved post when you return to it
